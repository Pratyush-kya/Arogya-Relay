# Security Policy

## Supported Versions

We currently support the latest version of the project on the `main` branch.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability, please report it privately. You can do this by navigating to the "Security" tab of this repository on GitHub and clicking "Report a vulnerability", or by reaching out to the maintainer directly.
