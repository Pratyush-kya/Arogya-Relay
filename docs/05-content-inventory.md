## Image / asset notes

- Avatars use **initials** (e.g., LM, AK) — no real faces, supports privacy in
  shared environments.
- Charts and the device illustration are rendered in CSS/SVG — no external image
  files required.
- A social-sharing (Open Graph) image is optional and not yet required.

## Copy guidelines

- Keep all health language **non-diagnostic** and framed as "screening support."
- Demo data is fictional; never present it as real patient records.
- Safety messaging (does not diagnose, apply local protocols) must stay visible.
